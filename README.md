## 🌟 Overview

This portfolio serves as a central hub to present my technical expertise spanning **Full-Stack Development**, **Cybersecurity & Penetration Testing**, **Systems Administration**, and **Database Engineering**. Built with performance and elegance in mind, it delivers a smooth, interactive experience without heavy third-party JavaScript frameworks.

---

## ✨ Key Features

- **Dynamic Interactive Background**: Interactive HTML5 Canvas particle network that reacts to screen sizing and subtle motion.
- **Custom Dual Cursor**: Smooth following dot and trailing halo cursor effect with hover scaling on interactive elements.
- **Animated Typewriter Hero**: Dynamic multi-role title cycling through core specializations.
- **Animated Metric Counters**: Smooth count-up animations for key portfolio statistics.
- **3D Tilt Cards**: Subtle mouse-driven perspective tilt on service and project cards.
- **Smooth Navigation & ScrollSpy**: Sticky navigation bar with active section highlighting and smooth scrolling.
- **Full Responsiveness**: Mobile-first design adaptable across mobile phones, tablets, and wide desktop screens with a hamburger drawer.
- **Modern Glassmorphic Dark UI**: Deep dark aesthetic with gold accents (`#d4a84b`), subtle border glow, and clean typography.
- **Interactive Contact Form**: Polished floating-label form inputs and direct contact avenues.

## 🚀 Getting Started

To run this portfolio locally on your machine:

### Prerequisites
All you need is a modern web browser (Google Chrome, Firefox, Safari, Edge) and optionally a lightweight local server.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/TimKeiK/personal-portfolio.git
   cd personal-portfolio
   ```

2. **Open the project**:
   - **Directly in browser**: Double-click `index.html` or open it with your browser.
   - **Using VS Code Live Server**: Right-click `index.html` and select **"Open with Live Server"**.
   - **Using Python's built-in HTTP server**:
     ```bash
     # Python 3
     python -m http.server 8000
     ```
     Then navigate to `http://localhost:8000` in your browser.
   - **Using Node `npx serve`**:
     ```bash
     npx serve .
     ```

## 🌐 Deployment

### GitHub Pages (Recommended)
This repository is pre-configured for static hosting. To publish via GitHub Pages:
1. Go to your repository settings on GitHub: **Settings > Pages**.
2. Under **Build and deployment > Source**, select **Deploy from a branch**.
3. Choose the branch `main` and folder `/ (root)`, then click **Save**.
4. Your site will be live at:
   ```
   https://<username>.github.io/personal-portfolio/
   ```
